# Hunger-s-Hunt
Hunger's Hunt is a responsive web application that helps users discover popular restaurants, cafes, and fast food places in their city. It features search, category filtering, Google Maps integration, and real restaurant data. Built using HTML, CSS, and JavaScript.
# 🍔 Hunger's Hunt

Hunger's Hunt is a responsive web application that helps users discover restaurants, cafes, and fast food places in their city.

## Features

- 🔍 Search restaurants by name
- 🍔 Category filtering
- 📍 Google Maps integration
- 📞 Contact information
- 📱 Responsive design
- 🚫 "No Results Found" screen
- ⭐ Real restaurant data

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Future Plans

- Fetch restaurant data using APIs
- User reviews and ratings
- Restaurant owner accounts
- Location-based recommendations
- Backend and database integration
